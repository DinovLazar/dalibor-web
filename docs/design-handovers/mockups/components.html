3 · Drop cap

CSS ::first-letter only — DOM text is intact for screen readers. Works in Cyrillic and Latin.

Во почетокот на секоја книга постои тишина — миг пред првиот збор, кога сè е сè уште можно. Тој миг го носам со себе секогаш кога седнувам да пишувам за туѓ текст.

At the beginning of every book there is a silence — the moment before the first word, when everything is still possible. I carry that moment whenever I sit to write about someone else's text.
